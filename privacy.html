プライバシーポリシー

「半券」（LIVE TICKET STUB）は、招待した人だけが使う、ライブの記録と予習プレイリストのアプリです。このページは、アプリが何を取り、どう使い、いつ消すかを書いています。

取るデータ

  • Google アカウントの名前とメールアドレス（ログインと、招待した人かどうかの確認に使います）。
  • YouTube のチャンネル名（設定の画面に「どのチャンネルにつながっているか」を出すために使います）。
  • YouTube につなぐための鍵（トークン）。暗号化して保存し、ブラウザからは読めません。
  • あなたが登録したライブ（日付・会場・ライブ名・メモ・出演者）、プレイリストと曲の記録、見つけた YouTube の動画の ID とタイトル。

使い方

  • 上のデータは、このアプリの機能（ログイン、ライブの記録、予習プレイリストの作成、YouTube Music への保存）のためだけに使います。広告には使わず、売ったり、ほかの人に渡したりしません。
  • YouTube の権限（youtube）は、「YouTube Music に保存」を押したときだけ求めます。あなたの YouTube にプレイリストを作る・中身を入れ替えるためにだけ使い、ほかのデータは読み書きしません。
  • アーティスト名と曲名は、曲の候補を探すために、iTunes Search API、Last.fm、YouTube Data API に送ります。メールアドレスなどは送りません。
  • セトリの画像を読み取るときだけ、その画像を Google Cloud Vision API に送り、文字を読み取ってもらいます。半券は、画像も、読み取った文字そのものも、保存しません（保存するのは、読み取りの結果をもとにあなたが整えた曲の記録だけです）。Google は、即時の読み取り（images:annotate）では画像をメモリ上で処理してディスクに保存せず、Google のモデルの学習や改善にも使わないとしています（出典：Google Cloud「Vision data usage」 https://docs.cloud.google.com/vision/docs/data-usage、2026年11月22日に確かめました）。貼り付けた文字は、どこにも送りません。
  • データは Supabase（データベースのサービス）に置いています。自分のデータは、自分だけが読み書きできるようにしています。
  • 半券による Google の API から得た情報の利用は、Google API サービスのユーザーデータに関するポリシー（限定的使用の要件を含む）に従います。YouTube の API サービスを使うため、YouTube 利用規約と Google のプライバシーポリシーも適用されます。

保存する期間

  • 動画を探した結果の共有の控え（動画の ID・タイトルなど）は、30日を過ぎたら消します。あなたのプレイリストの曲についた動画の ID・タイトルは、30日を過ぎたら YouTube で確かめ直し、確かめられないまま60日を過ぎたものは空にします。
  • YouTube の鍵とチャンネル名は、つないでいる間だけ保存します。切断すると、すぐに消します。つなぐ途中で確定しなかった鍵は、10分で使えなくなり、毎日の片付けで消します。
  • ライブ・プレイリストの記録は、あなたが消すまで保存します。ライブを消すと、そのライブの出演者と、アプリの中のそのライブのプレイリスト・曲の記録も一緒に消えます。YouTube にすでに作ったプレイリストは消えないので、YouTube Music で自分で消してください。

取り消し方

  • アプリの「設定」の画面で、YouTube との接続を切断できます。切断すると、保存していた鍵をすぐに消し、Google 側の許可も取り消します。
  • Google のアカウントの画面からも、いつでも取り消せます：https://myaccount.google.com/permissions（「半券」を選んで、アクセスを削除します）。
  • 記録のすべてを消したいときは、下の連絡先に伝えてください。

連絡先
