# 半券（LIVE TICKET STUB）

ライブに行く人のための PWA。ライブの予定を登録し、出演者の予習プレイリストを作って YouTube に保存する。

- アプリ：https://manekineko1119.github.io/hanken/
- プライバシーポリシー：https://manekineko1119.github.io/hanken/privacy.html
- 招待制。招待された Google アカウントだけがログインできる。
